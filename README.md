# NewsRadar

내 분야 소식을 매일 정한 시간에 모아, 흐름별로 묶은 한 화면으로 보여 주는 프로그램입니다.
내 PC에서 돌고, 정리는 내 Claude 계정이 합니다.

> 아직 만드는 중입니다. 지금은 설치해서 쓸 수 없습니다.

## 이런 분께

- 매일 따라가야 할 소식(회사 소식, 제품 발표, 업계 기사, 블로그)이 여러 곳에 흩어져 있는 분
- 분야는 상관없습니다. AI, 보안, 클라우드, 금융, 마케팅 등 무엇이든 정할 수 있습니다

## 하루 흐름

1. 정한 시간이 되면 내 PC가 여러 출처에서 새 소식을 모읍니다
2. Claude가 소식을 흐름별로 묶고, 내 일에 어떻게 쓸 수 있는지 한 줄씩 적습니다
3. PC 알림이 옵니다. 누르면 오늘의 정리 화면이 열리고, 제목을 누르면 원문으로 갑니다

## 필요한 것

- Windows PC (Mac은 준비 중)
- Claude 계정 (Pro, Max, Team, Enterprise)

## 설치

준비 중입니다.

## 알아 두기

- 소식을 모으고 정리하는 일은 모두 내 PC에서 합니다. 내 설정과 기록은 내 PC에만 남습니다
- Claude 사용량은 하루 한 번, 소식 목록을 읽는 정도입니다
- PC가 꺼져 있던 날은 다음에 켤 때 정리합니다
- PC 두 대에 설치하면 각각 따로 돕니다
