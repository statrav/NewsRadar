# NewsRadar

내 분야 소식을 매일 정한 시간에 모아, 흐름별로 묶은 한 화면으로 보여 주는 프로그램입니다.
내 PC에서 돌고, 정리는 내 Claude 계정이 합니다.

> 지금은 시험해 보는 단계(v0.1)입니다. 막히는 곳이 있으면 이 프로그램을 알려 준 분께 말씀해 주세요.

## 이런 분께

- 매일 따라가야 할 소식(회사 소식, 제품 발표, 업계 기사, 블로그)이 여러 곳에 흩어져 있는 분
- 분야는 상관없습니다. AI, 보안, 클라우드, 금융, 마케팅 등 무엇이든 정할 수 있습니다

## 하루 흐름

1. 정한 시간이 되면 내 PC가 여러 출처에서 새 소식을 모읍니다
2. Claude가 소식을 흐름별로 묶고, 내 일에 어떻게 쓸 수 있는지 한 줄씩 적습니다
3. PC 알림이 옵니다. 누르면 오늘의 정리 화면이 열리고, 제목을 누르면 원문으로 갑니다

## 필요한 것

- Windows 10 또는 11 PC (Mac은 준비 중)
- Claude 계정 (Pro, Max, Team, Enterprise)
- 인터넷

## 설치 (10분)

1. **[NewsRadar.zip 받기](https://github.com/statrav/NewsRadar/releases/latest/download/NewsRadar.zip)**
2. 받은 파일을 오른쪽 클릭 → **압축 풀기** (어느 폴더든 괜찮아요)
3. 풀린 폴더의 **`설치.cmd`를 더블클릭**
   - "파일 열기 - 보안 경고" 창(게시자를 확인할 수 없습니다)이 뜨면 **[실행]** 을 눌러 주세요
   - 처음 한 번은 필요한 프로그램을 설치하느라 몇 분 걸릴 수 있어요
4. 브라우저에 설정 화면이 열리면 차례로 진행하세요
   - **Claude 연결하기**: 브라우저에서 내 Claude 계정으로 로그인
   - **분야**, **받을 시각** 고르기
   - Claude가 고른 출처를 확인하고 **시작하기**
5. 첫 정리가 1~2분 뒤 자동으로 열립니다. 내일부터는 정한 시각에 알림이 와요

## 쓰는 법

- **오늘 정리 보기**: 바탕화면의 **NewsRadar**, 또는 알림을 누르기
- **분야·받을 시각 바꾸기**: 바탕화면의 **NewsRadar 설정**
- **Claude 연결이 풀렸다는 알림이 오면**: **NewsRadar 설정**을 열어 다시 연결 (회사 계정은 한 달쯤마다 필요할 수 있어요)
- **새 버전으로 바꾸기**: 새 ZIP을 받아 `설치.cmd`를 다시 실행 (설정과 기록은 그대로)
- **지우기**: 압축을 푼 폴더의 **`제거.cmd`** 를 더블클릭

## 알아 두기

- 소식을 모으고 정리하는 일은 모두 내 PC에서 합니다. 내 설정과 기록은 내 PC에만 남습니다
- 정리할 때 Claude는 전용 연결을 써서, 내가 따로 쓰는 Claude 설정과 섞이지 않습니다
- Claude 사용량은 하루 한 번, 소식 목록을 읽는 정도입니다
- PC가 꺼져 있던 날은 다음에 켤 때 정리합니다
- PC 두 대에 설치하면 각각 따로 돕니다
- **만든 사람에게 전달되는 것**: 설치를 마칠 때, 그리고 2주·한 달째 질문에 답할 때 **분야, 하루에 소식 보는 시간, 출처 수, 정리된 날 수**가 전달됩니다. 이름·메일·하는 일은 보내지 않습니다
